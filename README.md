

\# Student Management System



A full-stack Student Management System built using Spring Boot, React, and H2 Database.



\## Technology Stack



\- Java 21

\- Spring Boot

\- React.js

\- H2 Database

\- Spring Data JPA

\- Maven

\- Git and GitHub



\## Features



\- Add students

\- View students

\- Update student details

\- Delete students

\- Search students



\## Project Structure



\- backend: Spring Boot REST API

\- frontend: React application



\## Status



Currently under development.
